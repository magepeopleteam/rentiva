# Demo content

The bundled demo dataset (`inc/demo-import/sample-data.php`) matches the
approved mockup design exactly:

**Categories (6):** Bicycles, Scooters, Camping, Cameras, Water Sports,
Outdoor Gear.

**Locations (3):** Dhaka, Chittagong, Sylhet.

**Rental items (4):** Explorer X1 Mountain Bike ($18/day, $85/week),
Urban Cruiser ($14/day), Trail Master ($22/day), Weekend Pro ($16/day) — all
real `rbfw_item` posts with real pricing meta, so they behave exactly like
any other rental item (bookable, priced, filterable by category/location).

Explorer X1 additionally ships a full "Key Specifications" and "What's
Included" Feature List entry, matching the mockup's detail-page content, so
importing demo content gives you one fully fleshed-out example item to
model your own catalog on.

No demo photos are bundled — items render with the theme's placeholder
gradient card background until you add featured images, avoiding shipping
third-party stock photography with the theme package.

See docs/demo-import.md for how to run/re-run the importer.
