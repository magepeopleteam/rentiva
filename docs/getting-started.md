# Getting started

1. Install and activate, in this order: **WooCommerce**, **Booking and
   Rental Manager for WooCommerce**, **Elementor**, then **Rentiva**.
2. On activation, Rentiva shows a welcome notice (Appearance → Rentiva
   Settings, or the notice itself) — use it to import demo content.
3. Click **Import demo content** to create 6 rental categories, 3 pickup
   locations, and 4 demo rental items so the homepage and archive pages
   aren't empty while you build out your real catalog.
4. Visit **Appearance → Rentiva Settings** to set your own hero copy,
   promo banner, testimonial, colors, and social links.
5. Add real rental items under the plugin's own "Rentals" (or similarly
   named) admin menu — see the plugin's own documentation for pricing,
   availability, and item-type setup. Add specs/included-items via the
   Feature List field per docs/customization.md.
6. Set up menus at **Appearance → Menus**: Primary Navigation, Footer —
   Explore/Company/Support. Sensible defaults render automatically if you
   skip this step.

See docs/installation.md for plugin requirements and docs/theme-settings.md
for the full settings reference.
