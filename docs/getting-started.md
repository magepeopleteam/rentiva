# Getting started

1. Install and activate, in this order: **WooCommerce**, **Booking and
   Rental Manager for WooCommerce**, **Elementor**, then **Rentiva**. (All
   three are declared as required plugins in `style.css`, so WordPress
   prompts for them on the Themes screen if any are missing.)
2. On activation (with Elementor active), Rentiva automatically creates a
   "Homepage" page — pre-built out of the theme's 9 Elementor section
   widgets — and sets it as your static front page, so the homepage is a
   real, fully editable Elementor page from the start. A one-time welcome
   notice appears too, and the **Rentiva** admin menu (with its **Setup**
   and **Theme Settings** submenus — see docs/architecture.md) stays
   available afterwards, along with a compact "Rentiva Setup" Dashboard
   widget.
3. Open the **Homepage** page in Elementor (Pages → Homepage → Edit with
   Elementor) to rearrange, remove, or duplicate sections — or use the
   **Edit Homepage** tile on **Rentiva → Setup**.
4. Click **Import Demo Content** on **Rentiva → Setup** to create 6 rental
   categories, 3 pickup locations, and 4 demo rental items so the homepage
   and archive pages aren't empty while you build out your real catalog.
5. Visit **Rentiva → Theme Settings** to set your own hero copy,
   promo banner, testimonial, colors, and social links.
6. Add real rental items under the plugin's own "Rentals" (or similarly
   named) admin menu — see the plugin's own documentation for pricing,
   availability, and item-type setup. Add specs/included-items via the
   Feature List field per docs/customization.md.
7. Set up menus at **Appearance → Menus**: Primary Navigation, Footer —
   Explore/Company/Support. Sensible defaults render automatically if you
   skip this step.

See docs/installation.md for plugin requirements and docs/theme-settings.md
for the full settings reference.
