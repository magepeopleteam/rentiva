Create a premium, modern, highly polished rental and booking website template called **“Rentiva”**.

The template is designed for ThemeForest and must look like a **top-selling premium marketplace/booking template**, not a generic SaaS website.

The website should support multiple rental businesses such as:

* Bicycle rental
* Scooter rental
* Motorcycle rental
* Camping equipment
* Sports equipment
* Camera rental
* Outdoor equipment
* Tools and machinery
* Other rental products

The design must be generic enough that buyers can easily adapt it to different rental businesses.

## DESIGN GOAL

The first 5–10 seconds must create a strong **“WOW” impression**.

The visual direction should be:

* Premium
* Elegant
* Modern
* Editorial
* Clean
* Image-driven
* Highly trustworthy
* Easy to explore
* Conversion-focused
* Minimal but visually rich

Do NOT make it overly complicated.

Avoid:

* Excessive gradients
* Excessive glassmorphism
* Too many colors
* Tiny typography
* Overcrowded sections
* Excessive animations
* Complicated navigation
* Generic SaaS-style layouts

Use generous whitespace, beautiful photography, strong typography, large visual elements, rounded cards, subtle shadows and excellent spacing.

Use a sophisticated neutral color palette:

* Off-white / warm white background
* Near-black typography
* One premium accent color such as deep green or electric lime
* Very subtle gray borders
* Minimal use of accent color

Typography should feel premium and contemporary. Use a combination similar to:

* Headings: Sora / Manrope / Plus Jakarta Sans
* Body: Inter / DM Sans

Use large bold typography for major headlines.

Use approximately 16–24px border radius for major cards and components.

Design at desktop-first resolution around 1440px wide, but make the entire experience responsive for tablet and mobile.

# RESPONSIVE DESIGN

Create responsive versions for:

* Desktop 1440px
* Tablet 1024px
* Mobile 390px

On mobile:

* Header becomes compact with hamburger menu
* Hero typography scales down
* Search panel becomes vertically stacked
* Category cards become horizontally scrollable
* Product grids become 1-column or 2-column where appropriate
* Rental details gallery becomes swipeable
* Booking card becomes a sticky bottom booking bar
* “Reserve Now” remains easily accessible
* Maintain generous spacing and readability

# IMPORTANT DESIGN PRINCIPLE

The final result should feel like a **premium ThemeForest marketplace template that could compete with modern commercial booking/rental templates.**

It should NOT look like:

* A basic Bootstrap template
* A generic WordPress theme
* A SaaS dashboard
* An overly complicated marketplace

It should feel like:

**Airbnb + modern outdoor brand + premium rental marketplace**

with a strong visual identity and extremely simple UX.

Prioritize:

1. First-impression visual impact
2. Beautiful photography
3. Typography
4. Clear rental/search flow
5. Conversion
6. Whitespace
7. Consistency
8. Responsive design

The final design should be polished enough to present as a professional ThemeForest product demo.
